Work in Hospital EPR

Open Northbank General with your team's key. Hospital EPR opens the Patient List Manager. Select a row to manage an attendance, or select the patient's name to enter the chart.

Register and progress an attendance​

  1. Choose Register A&E attendance and find a synthetic patient.
  2. Enter the presenting complaint, acuity, and location. A responsible clinician is optional at registration.
  3. Register the attendance, then select its row in A&E tracking.
  4. Enter a responsible clinician and choose Start assessment.
  5. Choose Refer to medical take, then open Medical take.
  6. Enter the inpatient location and choose Admit to entered location. The patient moves into Inpatient census.

Use Save assignment to update the location, acuity, or responsible clinician. To finish an attendance, enter its discharge outcome and choose Discharge. Completed attendances remain in Discharged. Discharging an attendance does not write or send a discharge letter automatically.

Read the waiting measures​

Current mean wait uses people still waiting for assessment. Mean assessment wait · arrivals today uses people who arrived today and have an assessment time. In A&E ≥4 hours counts current A&E attendances that have reached four hours. A&E tracking includes patients awaiting the medical take.

The measures use the team's simulation clock. They describe this world's attendances and are not national hospital statistics. Change time through Simulation controls and refresh the lists to observe the effect.

Work in a patient chart​

Use Documentation for the document list and readable note preview. Notes show sections vertically, with their original author and later changes. Create a draft, review and sign it, or add an attributed addendum to a signed note. Follow Clinical records and hospital orders.

Prescription and Request test open separate catalogues and order details. Orders retains the submitted fields. Results shows a laboratory flowsheet with sample dates in columns and controls for trends. Pharmacy must review and approve a new prescription before dispensing.

Use Discharge summaries and Document Inbox to write and send a handover to the GP. Use Handover for related tasks and onward-care records. Creating a task, arranging a visit, and sending a letter are separate actions.

Agent requests​

GET /api/sites/hospital/attendances returns attendance resources, patient names, and simulation time. Submit mutations to /api/sites/hospital/actions using the team's bearer key.

Create with type: "register_attendance", patientId, title, acuity, and location. clinician is optional. Update with type: "update_attendance", resourceId, expectedVersion, and hospitalCommand, one of assign, assess, refer, admit, or discharge. Include the fields needed by that transition, such as a clinician for assessment or disposition for discharge.

Use the API explorer for request schemas and supported values. Reuse the same idempotency key for an identical retry and reload after a version conflict.
