Choose a workplace​

Open the neighbourhood map. Each location opens a desktop with its apps. The map gets out of the way inside the workplace.

  • Riverside Practice offers GP Records, Document Inbox, and Messagey.
  • Northbank General opens Hospital EPR.
  • High Street Pharmacy opens Pharmacy.
  • Neighbourhood Care opens Community Care.
  • At home offers Home Health and patient Messages.

One team key opens one isolated world. The portals and APIs read the same records. Use the same patient identifier across workplaces to follow a handover. Actions can schedule work, reserve capacity, or make a record visible to another service. Advance the clock to observe delayed results.

Use the records​

  • Team access and simulation time covers onboarding, the key, patient selection, and the activity trail.
  • Appointment sessions and slots covers booking, protected time, and session management.
  • Clinical records and hospital orders covers narrative journals, signed notes, prescriptions, and blood tests.
  • Discharge letters and GP document processing covers hospital drafts, sending, GP review, filing, tags, and codes.
  • Patient workflows follows records across services without assigning a hackathon challenge.

Build an integration​

Start with your first API call, then use the API reference and interactive API explorer. OpenAPI JSON is available for client generators and agents. The handbook JSON contains the published guides with their titles, URLs, and source text.

Use PDS and ODS FHIR APIs for demographics and organisations, Staff Identity for staff sign-in, or the legacy browser workflow for HTML-only document transfer.

Understand the world​

Read the data guide for fictional identities, authorship, record visibility, and production-derived aggregate counts. The population guide explains reproducible people, public appointment statistics, and isolated team changes.

The ten-year plan guide connects the plan's themes to existing patients and workflows. You choose what to build. Run the event covers operator setup, incidents, and verification.
